**Правило:** прежде чем искать что-либо «руками» или заново — используй готовые локальные поисковики по Второму Мозгу Антона. Выбор инструмента по типу запроса (дешёвый раньше дорогого):

1. **Точное имя человека/компании** (в любом написании — translit, раскладка, опечатка) → **`/find <имя>`** (`names.db`, 0 токенов).
2. **Слова/фразы ВНУТРИ переписок** (Telegram, Facebook, ChatGPT, Claude…) → **`/search <слова>`** (BM25/FTS5 по ~99k чатов, 0 токенов). Визуально: **http://127.0.0.1:8771**.
3. **В каком ЧАТЕ это было** (по названию чата) → `/search --chats` или `find_chat.py` (`dialogs.db`).
4. **Концептуальный вопрос «что я думаю про X / что у меня по теме»** → **`/ask <вопрос>`** (смысловой RAG по курируемому волту).

**Применяется к:** живым ассистентам Антона И AI-агентам — единый набор инструментов поиска для всех.
**Почему:** не начинать с нуля и не жечь токены, когда ответ уже лежит в индексах (закон токен-экономии).
