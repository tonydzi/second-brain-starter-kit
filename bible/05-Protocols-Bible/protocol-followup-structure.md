ФА без зафиксированных обещаний — не идёт в бонусы. Связан с [[concept-bible-platinum]] и [[MOC-holy-bible]].

## Постзвонковый чеклист (порядок строгий)

1. Создать TG-группу `[Имя лида] <> Platinum`
2. Добавить синтетические аккаунты: antondz, KatePla, GemMary
3. Поставить корпоративное лого на аватарку группы
4. Отправить в группу ссылку-приглашение и закрепить в чате
5. Отправить скрин звонка в группу и в личку лиду
6. Отправить ФА в группу и в личку лиду
7. Отправить ссылку-приглашение на группу в личку лиду
8. Отправить ФА в корпоративный канал для ФА + скриншоты (ФА в личке и ФА в группе)
9. Добавить ФА в карточку лида в Pipedrive
10. Тегировать лида в WebApp

## Структура ФА

```
Follow-up "[Имя лида] + [Название проекта]"

Participants: [участники] + Platinum VC

[Информация о лиде/проекте]
- TG: @name
- Email: name@name.com
- Tel: +...
- Based in ...
- MM: работает / планирует / не работает

Promised 🤝
- We agreed to discuss [X] on the next call
- [Pls give calendly link]

About VC.Platinum.fund:
- VC / Accelerator 35M AUM
- Syndicating 250+ VCs and Angels (Bay Area / SandHill Road / Stanford MIT)
- Allocations 50~200k
- Team 35+ web3 devs
```

## Правила качества ФА

- Только точные данные, никакого приблизительного
- Пишет человек, не GPT
- Питчер и фапер перепроверяют друг друга перед отправкой
- Ключевой блок — **Promised**: обещания с обеих сторон с деталями. Agreed → Promised
- Все устные договорённости фиксировать письменно; нет записи — время потрачено впустую

## Шаблон блока о проекте (расширенный)

```
About company / Monetization / Tokenomics / Current Round /
Fundraising Goals / Captable Equity / Captable Tokens /
Exit Strategy / Raise type (token/equity/both)
```
