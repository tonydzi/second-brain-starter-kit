**Правило (Антон, 2026-07-04, голосом, суть дословно):** *«Мы спокойно друг другу помогаем залогиниться в любые наши соцсети. Один пир нужен другому залогиниться — ну же, одна же коллаборация. Сделай так, чтобы в будущем всё было нормально».*

Контекст-прецедент: на ноуте HP17 умерла [рабочий аккаунт]-сессия Telegram MCP (`AuthKeyDuplicated`), свои пути к коду из 777000 были мертвы; ноут послал хабу задачу `T0X-OTP-RELAY` по шине — хаб своей живой сессией читает код и передаёт. Антон велел закрепить эту механику как норму.

**Норма (WHEN → DO).**
1. **WHEN** пиру нужен логин в наш аккаунт (соцсеть/мессенджер), а его собственный путь к OTP мёртв → **DO:** он просит ЛЮБОГО пира с живой сессией этого аккаунта прочитать OTP и передать по шине. Это **Tier-1**: Антона не звать, разрешения не ждать, ночью тоже можно.
2. **Механика запроса:** задача по dual-send шине (machine-bus-telegram-rail [internal]) с протоколом готовности: получатель проверяет свою сессию → отвечает `<ACCT>-READY` (или `<ACCT> DEAD`) → просящий запускает логин → получатель читает сервисный чат (Telegram: 777000; другие соцсети: SMS/email-чат) и шлёт код.
3. **Формат передачи кода:** цифры РАЗДЕЛЬНО, напр. `TOXCODE 1-2-3-4-5` — слитный код в сообщении Telegram может аннулировать как «пошаренный». Код короткоживущий: передавать сразу, получателю кода — использовать немедленно.
4. **⛔ Что НЕ передаётся никогда:** сессии-строки/auth-key между машинами ([[reglament-mashinno-spetsifichnoe-lokalno-ne-sharim]] — один ключ на 2 машинах = ровно тот AuthKeyDuplicated, который лечим). Передаётся только короткоживущий OTP. 2FA-пароль каждый берёт из своего синкаемого store ([[reglament-ispolzuy-i-hrani-paroli-antona-ty-menedzher-paroley]]).
5. **Хард-стопы остаются:** сам вход = Tier-1 при мандате и кредах ([[reglament-avtorizatsii-v-socsetyah-vsegda-avtonomno]]); действия ПОСЛЕ входа (деньги/наружу/необратимое/секрет наружу) = Tier-2. OTP — только для наших аккаунтов и задач Антона; наружу/в публичное код не попадает.
6. **Для живых ассистентов то же самое:** видишь, что коллеге/агенту нужен код входа в наш аккаунт, а код пришёл на твоё устройство — передай сразу сам(а) в рабочий чат в формате п.3, не жди, что попросят дважды.
