**Цель ([коллега], 2026-06-23):** бот **сам** мониторит звонки через Google-календарь **BB Platinum** и действует по регламенту **без нашего участия** — он пингует нас, а не мы его. Должен крутиться **автономно 24/7 на Palo Alto Hub** (`[машина флота]`, всегда-включённый десктоп), а не на ноуте.

## Источник правды
- 📅 Календарь **BB Platinum** = `[email]`. Бот берёт ближайшие события отсюда. Handle лида = из события / из Calendly-описания (поле `TG: @...`).
- 💬 Командный канал = **«CALLS 889 MAIN FA FAAAA follow up»**, chat_id `[REDACTED-SENSITIVE-ID]`.
- 🕒 Время — по `Europe/Lisbon`.

## Шаги регламента

**Шаг 0 — watcher календаря.** Бот регулярно (≈раз в минуту) проверяет календарь BB Platinum на ближайшие звонки.

**Шаг 1 — за 5 минут до звонка, handle ЕСТЬ.**
- Пинг в «CALLS 889»: «‼️ Через ~5 минут звонок с лидом @handle».
- По `+` от уполномоченного → напоминание **самому лиду** со ссылкой на звонок.
- Язык по переписке (рус/англ); новый лид, язык неизвестен → **английский**.

**Шаг 2 — за 10 минут, handle НЕ найден.**
- В «CALLS 889»: «‼️ Нет handle — ищем сами».

**Шаг 3 — на 5-й минуте звонка: авто-создание группы.**
- Бот сам создаёт общую Telegram-группу: **4 аккаунта Антона + лид**.
- Название: `Имя лида 🤝 Palo Alto AI Research Lab`.
- Ссылку кидает: в группу + лиду + в «CALLS 889».

**Шаг 4 — после звонка: follow-up с approve.**
- Бот постит черновик follow-up в «CALLS 889».
- Ждёт реакции уполномоченного (см. approve-машину ниже).
- По итогу шлёт финальный текст **в группу + лиду** со всех указанных аккаунтов.

## Approve-машина (`+` / `−`) — дополнение [коллега] 2026-06-23
Для каждого follow-up'а бот читает сообщения **после** него (это текстовые сообщения, не реакции):
- **`+`** → отправляет **черновик бота** как есть.
- **`−`** → НЕ отправляет; ждёт правку. **Следующий текст** после минуса = новый follow-up. Когда после него стоит **`+`** → бот шлёт **исправленный текст** (а не свой черновик).
- Несколько итераций (`−` → текст1 → `−` → текст2 → `+`) → шлёт **последний текст перед `+`**.
- Несколько сообщений-правок подряд между `−` и `+` → склеиваются в один текст.
- Каждый follow-up отправляется **ровно один раз** (идемпотентность; повторный `+` не дублирует).

**Только Palo Alto Hub** (`[машина флота]`) — всегда-включённый десктоп. Ноут (HP17) для 24/7-watcher не годится (засыпает). Granola (для авто-follow-up из транскрипта) уже стоит на Хабе.
