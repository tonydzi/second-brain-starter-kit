**Правило (Антон, 2026-06-15):** Всегда сначала использовать **все доступные лимиты, ВКЛЮЧЁННЫЕ в подписку** ЛЛМ, и только потом — **по согласованию с Антоном** — внешний **платный** API. Касается **ЛЮБЫХ ЛЛМ** (Claude, ChatGPT, Gemini и др.), кто бы ни выполнял работу — живой ассистент или AI-агент.

**Порядок:**
1. Сначала — **включённые в подписку баки** (например, у Claude: бак «Sonnet only» для грунт-работы, бак «Weekly all-models» для тяжёлого). Ещё раньше — бесплатные локальные инструменты (поиск/SQL/скрипты), если задача решается без ЛЛМ вообще.
2. Внешний **платный API / usage-credits — последний резерв, ТОЛЬКО по согласованию с Антоном.** Когда включённые баки исчерпаны/на пределе И дело не ждёт — сначала сказать Антону (какой бак полон, цена, более дешёвая альтернатива) и получить его ОК.

**Почему:** баки подписки уже оплачены и часто простаивают; платный счётчик — это новые деньги. Тратить платное, пока включённое лежит без дела, — слив денег.

**Применяется к:** ассистенты (живые) + AI-агенты, работающие от лица Антона или на его задачах.
**Граница:** платный API = расход → это и так требует подтверждения (деньги наружу). Качество результата важнее экономии: если дешёвый вариант ухудшает выход — эскалировать, не жертвовать качеством.
