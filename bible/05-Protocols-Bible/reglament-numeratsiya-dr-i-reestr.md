**Правило (WHEN → DO):** Каждый Deep Research (DR) получает уникальный номер **DRYY-MM-DD-МАШИНА-NN** — год, месяц, день, код машины-инициатора, порядковый номер за день у этой машины (DR26-07-03-ZB-01 = первый DR ноутбука 3 июля 2026). Номер выдаётся ДО выдачи промпта и вписывается в реестр `_DR-Registry.md` (корень волта). Правило Антона дословно (2026-07-03): «каждый депрезотч должен быть номер… если мы не будем вести реестр наших артефактов, у нас просто каша»; код машины — тоже его идея: «добавлял бы автора: какая машина инициировала — тогда нумерация не будет дублироваться».

**Почему машина в номере решает проблему синка:** каждый комп считает только СВОЮ очередь (HUB свою, ZB свою) — машинам не нужно договариваться и ждать синка, коллизия невозможна по построению. Коды: `HUB` = десктоп-хаб · `ZB` = ноут [машина флота] · `NAT` = комп [коллега] · новая машина = первые 4 символа hostname (скрипт определяет сам, hardcode не нужен).

**Зачем:** DR-ов много (десятки в день), без номеров непонятно, какой отчёт из ChatGPT/Gemini/Cowork к какому вопросу относится. Номер в заголовке промпта → внешний чат наследует его в название → выгрузка матчится с реестром автоматически.

**Как применять:**
1. **Выдал DR-промпт → сначала номер.** Машина: `python [путь владельца] new "<тема>" --tool chatgpt` (печатает ID и сам вписывает строку). Человек без скрипта: открыть `_DR-Registry.md`, взять следующий номер за сегодня, вписать строку руками.
2. **Номер — первой строкой промпта:** `# DR26-07-03-11 — <тема>`. Так чат внешней LLM называется по номеру.
3. **Счётчик сбился / не уверен, сколько было сегодня → +10** к последнему известному номеру (`--gap`). Дырки в нумерации не страшны, коллизии страшны.
4. **Файлы носят номер:** отчёт → `_originals\deep-research\DR26-07-03-11-<slug>-<vendor>.md`; Decision Memo и заметки синтеза ссылаются на ID.
5. **Статус ведём в реестре:** issued → running → collected → synthesized (или dead). Собрал отчёт → `dr_registry.py update <ID> --status collected --file "<путь>"`.

**ДО → ПОСЛЕ (реальные данные, 2026-07-03):** ДО — Антон выгружает DR из ChatGPT: чаты называются «Deep research», «Market analysis», непонятно какой файл к какому вопросу. ПОСЛЕ — чат называется «DR26-07-03-11 — Hetzner VPS anchor node», в реестре строка с темой, инструментом, статусом и путём к файлу; выгрузка матчится за секунду.
