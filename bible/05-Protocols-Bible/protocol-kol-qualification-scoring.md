# KOL Квалификация и скоринг

Связан с [[concept-bible-platinum]] и [[MOC-holy-bible]]. Смотри также Крипто-инфлюенсер-маркетинг [internal], [[concept-social-graph-leadgen]].

## Метрики оценки

**Основные сигналы качества:**
- Суммарный охват всех медиа-площадок KOL (TG-канал + Twitter + YouTube)
- Twitter-скор: количество постов о релевантных проектах и реальное вовлечение — проверяется прямо через профиль во время звонка
- Статистика YouTube — проверяется через VidIQ; при наличии запрашивается напрямую у KOL
- Накрутка: расхождение follower count / engagement rate — красный флаг, блокирует дальнейшую работу

**Ценовые ориентиры (СНГ):**
- Стоимость одного поста ~0.6 цента за охват
- Актуально для каналов 3k–15k юзеров
- Цена, которую KOL озвучил, vs цена, на которую сторговались — оба значения фиксируются

**Гео-фильтр:**
- Индусы и нигерийцы (и аналогичное) — не рассматриваются, бонусы за звонки с ними не выплачиваются

## Процедура верификации на звонке

1. Запросить статистику и портфолио кейсов до встречи или в начале звонка
2. Открыть Twitter профиль KOL прямо на звонке, проверить твит-скор
3. Для YouTube — запустить VidIQ параллельно
4. Зафиксировать: площадки, охваты, цену поста, язык контента, тематику

## Компенсация KOL

Варианты: USD в токенах проекта / USDT / трафик / комбинация двух-трёх форматов.
Аллокация KOL-раунда по цене близкой к VC — дополнительный инструмент для вовлечения без кеша.
