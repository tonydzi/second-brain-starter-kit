# Реглумент: Вожак / Ведомый — управление общим каноном на флоте

> Для ВСЕХ акторов (Антон + живые ассистенты + AI). Действует, когда мы ставим Claude Code + скиллы
> на машины коллег / учеников / семьи ([коллега], [коллега], [коллега], новые ПК/Маки). Не дублируем механику
> синка — она в [[reglament-migratsiya-mashin-playbook]] и журнале миграции.

## Принцип (Антон, 2026-06-22)
Общий **ЗАКОН** (что определяет ПОВЕДЕНИЕ и авто-разъезжается на все машины) меняет **только вожак**.
Всё, что делает машину **продуктивной** (её собственные скиллы, скрипты, работа), ведомый делает **сам,
без спроса**. **Гасить продуктивность нельзя** — гейт стоит ТОЛЬКО на общем каноне, не на работе.

## Роли
- **ВОЖАК = Антон**, операционно через **ХАБ** (`[машина флота]`, всегда-вкл, хранитель канона).
  Хаб — **единственная** машина, которая КОММИТИТ канон в синк.
- **ВЕДОМЫЕ** = машины коллег / учеников / семьи. Полные хозяева своей продуктивной работы.

## Два уровня изменений
### 🔴 КАНОН — верифицирует Антон (leader-gated)
Файлы, которые авто-распространяются на КАЖДУЮ машину и определяют поведение:
- `CLAUDE.md` (always-loaded поведенческий закон)
- Библия: `reglament-*` / `protocol-*` (свод для всех акторов)
- `operating-agreement` (конституция)
- standing-правила `MEMORY.md`

Их коммитит ТОЛЬКО вожак (через хаб). Ведомый их получает, но не пишет в канон.

### 🟢 ЛОКАЛЬНОЕ / ПРОДУКТИВНОЕ — автономно, БЕЗ гейта
Свои скиллы, скрипты, дашборды, ресёрч, черновики, импорты, повседневная работа.
Полная автономия. **Никогда не блокируем.**

## Как держится технически (АК-47, без новой инфры)
- Ведомая машина монтирует канон-папки (`claude-home` = CLAUDE.md+hooks+commands; папка Библии в волте)
  как **receive-only** в Syncthing → всегда ПОЛУЧАЕТ канон вожака, локальная правка авто-откатывается
  (Revert Local Changes к канону). Ничего не строим — это режим папки Syncthing.
  *(Точный механизм принуждения — receive-only vs git-ветка vs pre-commit hook — финализируется
  консенсусом с хабом по шине; дефолт = receive-only.)*
- **Ведомого НИКОГДА не затыкаем — он ПРЕДЛАГАЕТ.** Путь предложения:
  Claude на ведомой пишет предлагаемую правку канона в `[шина]/_transit/canon-proposals/`
  + пингует хаб по шине (`machine_bus.py send [машина флота] "..."`) → Антон смотрит → хаб вписывает
  в канон → синкается всем. **Ведомые ПРЕДЛАГАЮТ, вожак РАТИФИЦИРУЕТ.**

## ⚠️ ХУКИ (исполняемые автозапуски Claude) — файлы синкаются, но НА ВЕДОМОМ НЕ ИСПОЛНЯЮТСЯ (уточнение 2026-06-25)
Снимает противоречие: выше сказано, что canon-папка может включать `hooks`. Уточняем границу
**файл vs исполнение**: даже если файлы хуков прилетают в receive-only канон, ведомый их **НЕ вписывает
в свой `settings.json` и НЕ запускает** — его сток-Claude правильно ОТВЕРГАЕТ хук, сконфигурированный
хабом, как бэкдор (и это защита, а не баг). **Активные хуки ставятся ТОЛЬКО на ПОЛНЫЕ машины Вожака**
(хаб `[машина флота]`, его ноут, его Маки). Ведомому — только безопасный конфиг (ретенция
`cleanupPeriodDays: 3650`) + пуш своих сессий в общий волт (см.
[[reglament-multi-machine-claude-i-peredacha-mezhdu-mashinami]]). Канон ведомого v1 = **data-only**
(читает волт/скиллы/память/CLAUDE.md как данные; ничего тяжёлого и никаких хаб-хуков локально).
Пример 2026-06-25: `session_resume_hook` (recall прошлой сессии на старте) разнесён ТОЛЬКО на полные
машины; [коллега]/[коллега] ушли лишь ретенция + follower-пуш сессий, без хуков.

## Подача — НЕ унизительная (прямое требование Антона)
Никогда не говорим ведомому «у тебя доступ низкий». Говорим:
**«всё ок — правки канона просто ждут, пока Антон/хаб ратифицирует их в синк, чтобы общий закон
не разъезжался между машинами».** Это модель «единый хранитель общего закона», а не лестница допусков.
Своей продуктивной работой ведомый владеет полностью.

## Почему так
Если каждая машина свободно правит свой `CLAUDE.md` / Библию — копии разъезжаются (ровно то, против
чего предупреждают AK-47 и rules-intake: «копии разъезжаются = тот же затык»). Один хранитель = один канон.

## На онбординге новой машины ведомого
1. Общий стек знаний (волт-синк, скиллы, RAG, конфиг) — даём (см. [[reglament-migratsiya-mashin-playbook]]).
2. Канон-папки — выставить **receive-only** на ведомой.
3. НЕ ставим личные привязки Антона (TG-сессии, CRM-робот, его OAuth) — только хаб (§ playbook).
4. Объяснить Claude на ведомой: канон ты ПРЕДЛАГАЕШЬ через `_transit/canon-proposals/` + пинг хаба,
   не пишешь напрямую; всё своё — делаешь сам.
