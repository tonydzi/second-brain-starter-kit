# Реглумент: ретро начинай с RECALL других сессий

> Для ВСЕХ акторов (Антон + живые ассистенты + кремниевые агенты/LLM). Правило Антона
> (origin: anton): «Каждый раз, когда делаешь RETRO, сначала делай RECALL — убедись, что
> ДРУГИЕ сессии не сделали то же самое / похожее.»

## Принцип
Перед подведением итогов (ретро, отчёт о вехе, финал работы) — **СНАЧАЛА вспомнить, что уже
сделали ДРУГИЕ сессии / коллеги**, и только потом фиксировать своё. Это **частный случай
правила «RECALL перед любой активностью»** (capture-rules-into-bible [internal]): ретро — тоже
активность. Причина острая именно тут: я (Claude) запущен **одновременно на нескольких машинах
+ Cowork-флот**, волт общий → правило/скилл/заметку, которую «я» собираюсь записать, **уже мог
записать параллельный процесс**. Для живого ассистента то же: перед финалом проверь, не закрыл
ли коллега ту же задачу.

## Что проверяю (дёшево, детерминированно, ~0 токенов)
1. **Свежие ретро:** `ls` папки `01-Conversations\Claude\Retros\` (последние ~7) — нет ли ретро
   на ту же тему за сегодня от другой сессии? Есть → прочитать, не дублировать.
2. **Память + волт по теме:** grep `memory\` и нужной папки волта по правилу/концепту/инструменту,
   что трогала сессия — уже записано? → сослаться, а не писать близнеца.
3. **Страховка атрибуции:** машинный инвентарь (`retro_inventory.py`) ВКЛЮЧАЕТ артефакты других
   сессий (скиллы/скрипты/коммиты флота). Всё, что создано НЕ в этом разговоре — **чужое**:
   помечаю как чужое, не приписываю себе и не перемаршрутизирую (provenance-attribute-real-author [internal]).

## Результат шага
Одна строка в начале ретро: «проверил: N свежих ретро · тема уже покрыта … [internal] · вот эти пункты
инвентаря — от других сессий, не наши». Если durable-вещь уже зафиксирована параллельной
сессией — НЕ записываю повторно, только перелинковываю.

## Дом
Исполняемый канон — **Шаг 0 скилла `/retro`** (вшит). Это правило — поведенческая норма для всех
акторов; машинный подъём — память retro-recall-cross-session-first [internal]. Связано с тем, как мы
помечаем «кто/на какой машине сделал» (session-machine-tagging [internal]).
