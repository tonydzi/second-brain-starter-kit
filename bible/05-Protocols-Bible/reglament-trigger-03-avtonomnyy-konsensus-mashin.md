# Триггер «03» — машины сами находят консенсус

> Одобрено Антоном 2026-06-30 («я устал быть диспетчером между вами»). Антон часто просит компьютеры в коллаборации договориться друг с другом. Это даёт ему ОДНО короткое слово, после которого пиры всё делают сами, а его дёргают только на самом критичном. Поверх уже живого движка консенсуса (Phase 1) multi-machine-auto-consensus [internal].

## Когда срабатывает (триггер)
Антон произносит ЛЮБОЕ из (регистр не важен commands-case-insensitive [internal]):
- **«03»** (самое простое для Антона - это имя TG-чата, где машины согласовывают);
- **«003»** = тот же «03» (Антон 2026-07-02: так ещё быстрее набирать; лишний ноль игнорируем; ⛔ не путать с «02» - это эскалация К Антону, группа 02 POLICE);
- «теперь вы сами» · «дальше сами» · «договоритесь сами» · «решите между собой» · «найдите консенсус» · «автономно» · «САМИ»;
- «общайтесь через ТГ» · «общайтесь через 03»;
- скилл-вход **`/03`**.

Это МАНДАТ, а не вопрос: пиры-Claude (хаб + ноут + машины коллег) договариваются между собой И исполняют САМИ, без Антона-курьера.

## Как ведём себя — «анонсируй и иди», НЕ блокируй
1. **Анонс одной строкой, без ожидания «да»:** роняю `🤝 если не против, иду согласовывать с <пиры> через 03…` и СРАЗУ открываю предложение. Антон может отменить, но по умолчанию его НЕ ждём (это и есть «вы сами»).
2. **Сначала консенсус, потом действие.** Через `consensus.py`: `propose → counter → accept → commit`. Действие применяется ТОЛЬКО после согласия.
3. **Кросс-проверка (анти-«работает-у-меня»):** задача globally done лишь когда ОБЕ машины независимо постят `VERIFY` с доказательством (>=2). Один пир «сделал» - ещё не сделано.
4. **Всё видно в чате 03** - переговоры идут в открытую (дуальная шина TG-03 + `[шина]`), Антон может смотреть, но не обязан участвовать.

## Когда всё-таки будим Антона — РОВНО 2 ворот
Везде, где можно без Антона - без Антона. Эскалация только если:
1. **Действие Tier-2** (деньги · отправка наружу · необратимое · секреты · правка общего канона) - даже при полном согласии пиров оно НЕ авто-коммитится → уходит на дистанционное одобрение `QQQ` [[reglament-distancionnoe-odobrenie-qqq]].
2. **Пиры НЕ сошлись** по важному/необратимому за round-cap (3 раунда) или таймаут.

Всё остальное машины закрывают сами:
- **Безопасный обратимый класс (Tier-0/1)** + согласие → авто-исполнение.
- **Тупик по безопасному Tier-0** → лидер-хаб (`[машина флота]`) применяет tie-break «disagree-and-commit». Это НЕ повод будить Антона - спор закрывает лидер.

То есть Антон = только самый критичный остаток: либо непреодолимый спор, либо очень серьёзное (Tier-2) решение.

## Чем НЕ является (чтобы не путать)
- ⛔ Это НЕ «мои read-only субагенты внутри одной сессии» (то - multi-agent-offer-reflex [internal], синтез у меня).
- ⛔ Это НЕ «человеко-управляемые параллельные сессии» (то - decompose-into-parallel-sessions [internal]).
- ✅ Это межМАШИННЫЙ консенсус равноправных Claude-пиров на разных компьютерах.

## Границы (не отменяются триггером)
- Tier-2 хард-стоп остаётся: «вы сами» НЕ даёт право самим потратить деньги / отправить наружу / переписать канон. Такое всегда через `QQQ` Антону.
- Канон меняет только Антон через хаб machine-governance-leader-follower [internal] - пиры могут согласиться ПРЕДЛОЖИТЬ правку канона, но коммитит её лидер.
- Открытый вопрос (отдельный Deep Research): режимы отказа - «византийский» пир (врёт в VERIFY), авто-цикл предложений, ложное подтверждение. До закрытия DR держим Phase 1 консервативным (тупик/таймаут по чему-либо важнее Tier-0 → к Антону).
