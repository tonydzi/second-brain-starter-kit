**Правило (WHEN → DO):** ПРЕЖДЕ чем что-либо **убрать в архив / закрыть / пометить «готово» / прибрать с глаз** (заметку, проект, переписку с лидом, импорт, папку, пункт памяти) — **сначала проверь, не осталось ли там НЕДОДЕЛОК**, и если есть — **вынеси их на доску висячих задач**, а не хорони вместе с архивом. Архив = склад **ГОТОВОГО**; всё **недоделанное** живёт на доске, где маячит само. Правило Антона (origin: anton).

**Зачем:** «уберём в архив, а если вдруг вспомним — вернёмся» — это **ловушка**: память человека и ИИ ненадёжна, и реальная незакрытая задача (скачать оригинал, дослать ответ лиду, доимпортировать данные, доплатить, дописать скрипт) тихо умирает под ярлыком «сделано». Закрывать вещь можно только когда у неё **нет открытых хвостов** — иначе хвост идёт на доску, а в архив едет лишь завершённая часть.

**Как делать (АК-47):**
- **Скан на хвосты** перед архивацией: пробежать содержимое на маркеры незакрытого — «осталось / pending / заблокировано / TODO / отложено / ждёт / next / ⚠️ / Phase B / дослать / доплатить / доделать». Реальный открытый **хвост-действие** (а не просто грабли-урок «вот так не делай») = недоделка.
- **Хвост → на доску** висячих задач ([[reglament-visyachie-zadachi-vsegda-dashboard|доска висячих задач]], `_Dashboards\Hanging-Tasks-Dashboard.html`), сгруппировано по владельцу действия (🔴 Антон · 🟡 исполнитель · ⏳ внешнее/машины), чтобы всплывало само — НЕ «если вспомним».
- **Что закрыто по факту — отметь закрытым** (секция «✅ закрыто по recall»), не тащи в открытые.
- **Тогда архивируй** оставшуюся завершённую часть. Указатель в архиве сохраняется, оригинал не удаляется (preserve-originals-rule [internal]); поиск по архиву — точечный (grep/индекс), архив не грузится «по умолчанию».

**Пример (ДО → ПОСЛЕ), реальный (2026-06-26/27):** при чистке `MEMORY.md` 29 «готовых» записей уезжали в архив. ДО — отправить всё в архив скопом. ПОСЛЕ — сперва скан: нашлись настоящие хвосты — `youtube-history` (Takeout скачан, но в волт НЕ импортирован), `airtable` (дозабор), решения для Антона (PhD, charm-os). Они ушли на доску; а `father-emails` оказался **уже закрыт** (оригинал Takeout 171 МБ уже в `_originals`) → помечен ✅. В архив уехало только действительно завершённое.

**Граница:** правило про **событие архивации/закрытия**, а не про подачу аудита (это [[reglament-visyachie-zadachi-vsegda-dashboard]]). Если хвостов нет — просто архивируй, доску не трогай. Грабли-уроки (gotchas) — это знание, а не недоделка: они остаются в заметке, на доску не идут.
