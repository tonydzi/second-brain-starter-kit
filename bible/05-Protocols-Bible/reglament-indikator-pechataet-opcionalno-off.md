# Индикатор «печатает…» по умолчанию ВЫКЛ; включать только если userbot шлёт его надёжно и текст длинный

> Под-домен Библии «человеческий ритм и присутствие» ([[_Bible-Warm-Maintenance-MOC]]) · слой *2. Ритм печати и форма сообщений* · важность 2/5 · тип NEW. Одобрено Антоном 2026-06-12.

## WHEN → DO
КОГДА сообщение готово к отправке → ДЕЛАЙ ПО УМОЛЧАНИЮ: «печатает…» НЕ показывай — просто отправь после рассчитанной паузы. Индикатор включай ТОЛЬКО ЕСЛИ userbot/MCP умеет слать его надёжно (не мигает, не обрывается) И сообщение длиннее ~40 знаков: тогда покажи последние ~1 сек на каждые 12 знаков, потолок 8 сек. Для коротких реплик (<40 знаков: «ок», «да, давай») typing НЕ включай НИКОГДА. При дроблении — короткий всплеск 2–4 сек перед каждым куском. Любое сомнение, что typing уйдёт ровно → не шли его: тишина безопаснее кривого индикатора.

## Пример ДО → ПОСЛЕ
- ❌ **ДО:** Бот включает «печатает…» и держит 40 секунд, потом разом вываливает «ок, понял» (10 знаков) — классический след скрипта.
- ✅ **ПОСЛЕ:** Для «ок, понял» typing не показывается совсем — сообщение просто приходит после паузы. Для абзаца на 180 знаков «печатает…» мигает последние ~7 сек перед отправкой.

## Оговорка / анти-паттерн
Кривой/рваный индикатор палит СИЛЬНЕЕ его отсутствия — при малейшем сомнении в надёжности typing не отправляем вовсе.
