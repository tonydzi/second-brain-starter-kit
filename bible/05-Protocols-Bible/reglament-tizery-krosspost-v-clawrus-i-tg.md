# Регламент — тизеры в @ClawRus и TG-канал Антона

**Правило Антона (2026-06-30).** Каждый раз, когда Антон что-то **достиг / нашёл / опубликовал** (новый Facebook-пост, пост в его TG-канале, веха, релиз, находка) — в комьюнити **@ClawRus** (и в его TG-канал) постится **ТИЗЕР** со ссылкой на полный материал. Это **этап Distribute** content-factory [internal] — не отдельная система, а её рука раздачи.

> ⚖️ **Единый RU-таргет (Антон, 2026-07-01, CAPS «ВСЕ ПИСАТЬ СЮДА»):** всё RU (тизеры/лонгриды/дневник) → **@ClawRus** = мегагруппа `[REDACTED-TG-CHAT-ID]` (t.me/ClawRus). Отдельного broadcast-канала «ClawRush» У НАС НЕТ; **`@clawrush` — ЧУЖОЙ канал, постить туда ЗАПРЕЩЕНО** (openclaw-telegram-channels [internal]). Резолвить строго по числовому id `[REDACTED-TG-CHAT-ID]`, не по имени. Гит-репо-слаг `clawrush` — отдельно (переименование = решение Антона).

## Что делает актор (человек или LLM)
1. **Триггер:** опубликован новый FB-пост / TG-пост Антона, либо зафиксирована веха/находка (в т.ч. из дневника фабрики, FB-diary, devlog).
2. **Собрать тизер:** короткий крючок + ссылка на полный пост. Тон **по каналу** (короткий текст без проверки → ≤5, макс 7 слов; @ClawRus = тёплое RU-комьюнити): см. правило коротких текстов и author-voice.
3. **Голос Антона пишет Opus** (карв-аут авторского голоса), не Sonnet — даже черновик.
4. **Подача:** по умолчанию **draft-first** (черновик Антону → `+`/`QQQ` → пост), пока механика постинга не армирована. После проверки механики — автономно под рейт-гейтом (как `/fb-post` и `/fb-reply` под `fb_guard`), см. fb-skill-set [internal].

## Границы (Tier-2 не отменяется)
- Публикация публичного контента = outbound → **не «слепой автопостинг»**: деньги/обязательства/секреты/масс-флуд → пауза+спрос.
- Секреты и приватные имена/суммы НЕ утекают в тизер.
- Тизер ведёт на УЖЕ опубликованный Антоном материал — мы не раскрываем непубличное раньше него.
- Только в его собственные каналы (@ClawRus курирует Антон/@[рабочий аккаунт], и его TG-канал) — не рассылка по чужим.
