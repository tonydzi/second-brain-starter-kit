# 🏛️ Регламент — все нотификации и крики CC идут в ЧАТ 03

> Кросс-акторное правило (Антон + живые ассистенты + кремниевые агенты). Машина-канон: память cc-alerts-to-chat-03 [internal] + след в `MEMORY.md`. Связано: machine-bus-telegram-rail [internal], llm-free-transport-dumb-detector-first [internal], telegram-signals-inventory [internal].

## Правило (must)
**ВСЕ нотификации, алерты и «крики» (что-то сломалось / упёрлось в лимит / зависло / молчит / реконнект нужен), которые Claude Code (или любой актор от лица Антона) шлёт в Telegram, ВСЕГДА идут в ЧАТ 03** — семейно-клановую bus-группу `[REDACTED-SENSITIVE-ID]` («03 NAT+RUSL+ANT+AI … MAIN Work group»), **а НЕ в Избранное (Saved Messages)**.

Правило Антона дословно (2026-06-27): «ВСЕ НОТИФИКЕЙШЕНЫ И КРИКИ от СС которые он шлёт в ТГ — он всегда шлёт в 03 чат».

## Зачем
- **Один общий канал тревог:** в чате 03 сидят и люди (Антон, [коллега], [коллега]), и машины. Сломался хаб / замолчал крон / упал синк → видят ВСЕ, кто может помочь, а не только Антон в личном Избранном.
- **Согласовано с bus-рельсом:** машины уже говорят через эту же группу (machine-bus-telegram-rail [internal]); крики живут там же, где координация.

## Как (механизм)
- Слать через `bus_ping.post(text)` (0 LLM, Telethon `@[рабочий аккаунт]`, общий лок) — цель зашита `BUS_GROUP = [REDACTED-SENSITIVE-ID]`. НЕ `bus_ping.send()` (та по умолчанию в Saved — оставлена только для легаси-персонального).
- Из cmd: `python bus_ping.py --post "текст"`.
- **Формат крика = ПЛОСКИЙ человеко-читаемый текст** (🔴/🟠/🟢 + что и где), БЕЗ bus-конверта `[SRC -> DST]` — иначе детектор `bus_tg_peek` примет крик за машинную задачу. Конверт `[SRC -> DST]` — только для машина→машина задач, не для тревог людям.
- Уже переведены на чат 03: `robot_alert_guard.py` (inbox-робот: лимит/таймаут/ошибка), `cron_watchdog.py` (краны молчат/упали).

## Граница
- **РАСШИРЕНО до ВСЕГО (Антон, 2026-06-28: «вообще ВСЁ → чат 03»):** прежняя оговорка («персональный контент остаётся в Saved») ОТМЕНЕНА. Теперь ВСЁ — тревоги/нотификации/дайджесты И персональный контент (коуч, FB-дневник, контент-план, голос-триаж-пинг) — идёт в чат 03. Saved больше НЕ цель для пингов. Saved остаётся только за: (а) ИСТОЧНИК ЧТЕНИЯ собственного ввода Антона (голосовые, что он сам кладёт в Saved → читают voice-triage/content-factory; ответы коучу в переходный период), и (б) ссылка на identity аккаунта («account [рабочий аккаунт], id [id]»). Антон увидел и принял компромисс приватности: семья в чате 03 видит его коуч-разбор и черновики дневника.
- Tier-2 (деньги/наружу/обязательства) — всё равно к Антону отдельно, чат 03 не делает их авто-исполняемыми.
- **Supersede:** прежнее «алерты в Saved [id]» (telegram-signals-inventory [internal]) заменено этим правилом для ВСЕХ пингов (не только системных тревог).
