# Торговля трафиком: продажа и закупка

Связан с [[concept-bible-platinum]] и [[MOC-holy-bible]]. Смотри также Tap-to-earn игры и тапалки [internal], [[Токеномика]], [[concept-social-graph-leadgen]].

## Форматы продажи трафика

Два основных продукта:
1. Прайс-лист трафика с тапалки — фиксированная цена за юзера по сегментам
2. Настройка рекламного кабинета для лида — комиссия 10% от бюджета

Сопутствующие бонусы для лидов: бесплатное интро к другим тапалкам как leverage для снижения цены трафика; доступ в приватные группы покупки/продажи трафика.

## Квалификация трафик-партнёров

Если лид покупает трафик:
- Как верифицируем объём: платим за всех или только за уникальных юзеров?
- Если привели юзера, который уже был в их базе — платят?

Если лид продаёт трафик:
- Есть ли сегментация (Premium, активные, гео)? Прайс по каждому сегменту
- Как определяют "активного" юзера?
- Скидка за повторных юзеров?
- Как гарантируют качество и уникальность?
- Кейсы с конкретными конверсиями

Квалификация входящих (любой источник):
- Где уже покупали трафик, по каким ценам?
- Какая конверсия по купленному трафику?
- Куда наливали (бот/сайт/канал)?

## Посредническая (retainer) модель

Кейс WebSummit: [человек]-retainer заключает договор с лидом — обеспечивает трафик по низкой цене + делает коллабы. Монетизация — через интро к тапалкам (10–20 интро за обещание половинной цены трафика). Модель масштабируется без прямых затрат.

Принцип: интро к партнёрам как валюта — снижает цену трафика и создаёт комиссионный поток одновременно.

## Скрипт для питчеров при разговоре с фаундерами

Обязательный блок вопросов на каждом звонке:
- Покупаете ли трафик? Покупали раньше? Планируете?
- Кто в компании занимается закупом? Можете познакомить?
- Какие сервисы покупаете в целом?
- Довольны текущими поставщиками трафика?

Если спрашивают зачем: "У нас много партнёров с разными потребностями — собираем данные, чтобы дать вам лучшую цену и нужного партнёра."
