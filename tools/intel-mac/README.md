# Intel-Mac в флот второго мозга: комплект онбординга

Родился осенью 2026 на Mac Pro 2019 (Intel Xeon, macOS 15), когда публичные рунбуки набора
([ONBOARDING-MAC.md](../../ONBOARDING-MAC.md) и [ONBOARDING-FAMILY.md](../../ONBOARDING-FAMILY.md)) упёрлись в две вещи:
Homebrew на Intel больше не даёт готовых бутылок, а шара claude-home может привезти с хаба весь его `~/.claude`
вместе с секретами.

## Что здесь лежит

- [`ONBOARDING-MAC-INTEL.md`](../../ONBOARDING-MAC-INTEL.md): рунбук для робота и человека. Блок «руки оператора»,
  шаг 0 (профиль) и десять шагов с командой-доказательством, приёмка, ловушки Intel.
- [`onboard-intel-mac.sh`](onboard-intel-mac.sh): идемпотентный bash-скрипт, фазы
  `tools | claude | github | tailscale | telegram | syncthing | law | verify | all`, флаг `--dry-run`.
  **Профиль обязателен**: в скрипте нет ни одного значения по умолчанию про человека, узел, волт или хаб.
  Точка выхода одна; отказ гейта останавливает поток; пропущенная проверка = `SKIP` и итог `INCOMPLETE` (код 4),
  а не зелёный.
- [`profile.example.env`](profile.example.env): образец профиля с заглушками `CHANGE_ME`. Заполненный профиль
  живёт вне репозитория.
- [`gates.tsv`](gates.tsv): список гейтов данными: что защищает каждый и как подложить ему отказ.
- [`tgbus/`](tgbus/): помощники Telegram-рельсы без идентификаторов флота внутри (комната, метка агента и имена
  из окружения). Ввод человека только через окно: `secret_dialog.py` → [`../secret_prompt.sh`](../secret_prompt.sh).
- [`tests/`](tests/): `kill_gates.sh` (каждому гейту подложен отказ в одноразовом HOME), `test_helpers.sh`
  (дверь ввода и помощники Telegram), `mutants.py` (ломает гейты по одному и проверяет, что пробы краснеют),
  `fixtures/profile.smoke.env` (вымышленный профиль).
- [`../runbook_smoke.sh`](../runbook_smoke.sh): свежий клон во временный каталог, команды рунбука дословно до
  первого сетевого шага, `git apply --check` патча на закреплённых коммитах, поиск констант личности и секретов.

Быстрый старт: шаг 0 рунбука (профиль), затем `--dry-run tools`, потом фазы по одной, `verify` в конце и ещё
раз из новой сессии.

## Что доказано, а что нет

Честная граница, чтобы «работает» не было словом.

| Что | Как проверено | Статус |
|---|---|---|
| гейты скрипта (профиль, хэши, общая учётка, аккаунт GitHub, фильтр до приёма, путь папок, env F3, линк памяти, пропуски, отказ шага внутри фазы, запись сквозь симлинк, бэкап содержимым, повтор verify по журналу) | `tests/kill_gates.sh`: одноразовый HOME, сеть, launchctl, Syncthing REST, gh, claude, codex, uv и venv заменены подставными командами; скрипт байт-в-байт боевой | доказано в песочнице |
| пробы умеют краснеть | `tests/mutants.py`: каждый гейт сломан в копии, проба обязана покраснеть | доказано |
| рунбук исполним из свежего клона до первого сетевого шага | `tools/runbook_smoke.sh` (проверка `runbook`) | доказано на машине автора |
| ссылки на GitHub в документах открываются | `tools/runbook_smoke.sh` (проверка `links`): полный адрес, ветка и файл, отвечает 200; контроль: несуществующий файл не 200 | доказано (сеть) |
| патч 0002 на закреплённом коммите апстрима | `git apply --check` (без `--3way`) в `runbook_smoke.sh` | **красное**: на `messages.py` патч чисто не ложится; фаза `telegram` остановится на `G-TG-PATCH`. Ждёт решения владельца набора патчей |
| дверь ввода: формат до сети, отказ без GUI, значение не попадает в вывод | `tests/test_helpers.sh` с подменой окна | доказано с подменой; **настоящее окно macOS не нажималось** |
| фазы `claude` и `tailscale` | только `--dry-run` и чтение кода: в них абсолютные пути (`/usr/local/bin/brew`, `/Applications`) | **не проверено** |
| живой прогон любой фазы после переписывания под профиль и гейты | не выполнялся ни на одной машине | **не проверено** |
| прогон на чистой учётке macOS или на другом узле | нужен пароль администратора и человек | **не проверено, гейт открыт** |

Свежий клон на машине автора ловит «работает только из моей папки», но переносимость не доказывает: её
доказывает только другая учётка или другой узел.

## Почему Intel особенный

- **Homebrew на Intel macOS = Tier 3 с сентября 2026**: бутылок для git/node/python/ripgrep/coreutils/syncthing/gh нет, `brew install` собирает из исходников (ставит Rust и LLVM, часы) и может упасть. Casks работают. Выход: вендорные бинарники в папке узла с проверкой SHA256, coreutils собираем сами ради `gtimeout`.
- **GPU только Metal 2**: ни CUDA, ни ROCm. Ollama на Intel-Mac = CPU-only, PyTorch больше не выпускает колёса под x86 macOS, GPU-путь только llama.cpp и whisper.cpp через Metal. Роль такой машины: архив и сервер, не инференс.
- **Колёса Python кончаются**: у `cryptography>=47` нет сборки для x86_64 CPython, `uv sync` telegram-mcp падает, пока в `pyproject.toml` не встанет `[tool.uv] override-dependencies = ["cryptography<47"]`.
- **Tahoe 26 = последняя macOS для Intel**: обновлений системы дальше не будет, всё, что ставим, должно жить без них. Путь Homebrew здесь `/usr/local`, не `/opt/homebrew`.
- **Синк большого волта медленный**: мелкие файлы идут по LAN единицы-десятки в секунду (часы). Планируй приём волта на ночь.
