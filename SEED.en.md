   right now; save the result as the first note in the vault.
4. "Tell me about yourself" interview (15–20 minutes): my role, how my
   work process runs, where my data lives, my communication style. Every
   meaningful answer → a note in the vault.
5. Privacy baskets: 🟢 work · 🟡 personal · 🔴 very personal (local only).

## Standing rules (they go into my CLAUDE.md)
- Every decision, agreement, idea, material → into the vault, linked.
- End of session → memory check: "what did you learn about me → saved?" + receipt.
- Before I contact someone from my CRM — pull up their card first.
- Answer in plain words; anything complex ends with a short "in simple words" block.
- The simplest solution I can fix myself; add complexity only with an
  explanation of which pain it cures.
- Before changes — show "before → after" on my real data, then ask "go?".
- Money / deleting data / sending anything in my name / other people's
  personal data going out → always pause and wait for my explicit OK.
- If I do the same thing a second or third time — suggest turning it into a skill yourself.
