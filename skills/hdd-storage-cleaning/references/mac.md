# Mac: размер, восстановление, чистка

## Замер без изменений

Сначала версия macOS (`sw_vers`), текущий пользователь и том с его HOME. Примеры независимых команд:

```sh
df -k "$HOME"
diskutil apfs list
tmutil listlocalsnapshots /
du -x -k -d 1 "$HOME"
```

Сохраняй exit-код каждой команды и ошибки доступа. `du` может долго работать: получай промежуточный статус, не повторяй полный обход. Уточняй крупные ветви. Не скрывай ошибки, если затем заявляешь полный охват. `-x` ограничивает обход файловой системой; отдельные диски измеряй отдельно.

`df "$HOME"` обычно показывает Data, а `diskutil info /` может показать только системный snapshot. Используй список APFS для контейнера и томов. System и Data делят контейнер: не складывай их общий free. System Data — категория интерфейса, а не папка для удаления. [Apple: просмотр хранилища](https://support.apple.com/en-us/102624).

У обычного локального файла `stat -f '%z %b %N' "$task_file"` показывает логический размер в байтах и число блоков по 512 байт. Назначь `task_file` проверенному пути; не применяй это для секретных хранилищ. APFS clones/hard links и snapshots осложняют сумму: она не равна гарантированному освобождению. Проверяй inode/hard links при поиске дублей. У sparse/compressed-файлов логический размер может превышать занятый.

Не читай/хэшируй облачные placeholders ради замера: чтение может скачать данные. Размер облачной папки интерпретируй вместе со статусом File Provider и фактически локальными файлами.

Если Photos/Mail или другие ветви недоступны, отметь нижнюю оценку. Для необходимого полного аудита может понадобиться Full Disk Access приложения, запускающего команды, и его перезапуск; затем проверь доступ повторно. Не запрашивай лишний доступ ради уже решённого вопроса.

## Важные кандидаты

| Объект | Что проверить до действия |
|---|---|
| `~/Library/Caches` и кэш пакетного менеджера | Конкретный владелец, закрытие приложения, способ пересоздания; его поддерживаемая команда для выбранного кэша. Не очищать всё дерево. |
| Application Support, Containers, Group Containers, Mail, Mobile Documents | Часто уникальные данные. Не считать кэшами и не копировать/удалять целиком. |
| Остатки приложения | Разделить программу, загрузки/индексы и пользовательскую БД. У кошелька blockchain может пересоздаваться, wallet/key store — отдельные защищённые данные. |
| Docker/VM/модели | Образ диска может содержать базы и volumes. Сначала инвентарь владельца; prune-volumes или удаление образа не являются обычной чисткой кэша. |
| Загрузки/установщики | Пользовательская ценность, доступность точной версии и копия. Старый возраст не является разрешением. |
| Trash | Возможны единственные кошельковые данные. Не очищать целиком; перенос сюда не считать освобождением. |
| Time Machine/APFS snapshots | Тип и роль. Снимок ОС и бэкап не являются ненужными дубликатами. Не удалять и не менять автоматический бэкап без отдельного решения. |

Time Machine сам управляет локальными снимками по возрасту и потребности в месте; macOS может учитывать их как доступное пространство. Отдельно фиксируй free и метод; не обещай освободить весь размер snapshot. [Apple: локальные снимки](https://support.apple.com/en-us/102154).

## Migration Assistant и удалённый Mac

Убедись, что подключился к нужному устройству: hostname, архитектура, пользователь, UID и ёмкость. SSH alias может вести к другому компьютеру. `/usr/bin/python3` на новом Mac может оказаться заглушкой для установки developer tools: сначала проверь runtime, используй доступные штатные средства.

Staging может находиться в пользовательских папках или внутри `/private/var/folders/.../Cleanup At Startup/...`. Найди его по процессу/инвентарю, не по угаданному UUID. Работающий migration helper не доказывает завершение переноса. Здесь могут быть ключи и единственные документы; не удаляй корень и не перезагружайся ради автоматической очистки.

Для обычных файлов применяй манифест из SKILL.md. Проверь free принимающего тома до копирования и во время большого пакета. Не перезаписывай актуальные профили старой staging-копией. На Apple Silicon выбирай совместимую сборку приложения; установка Intel-версии/Rosetta — отдельное решение.

Для браузера штатно закрой оба экземпляра, проверь WAL, сохрани состояние назначения. Выбирай конкретные профили/файлы; automation-профили и кэши не нужны автоматически. Допуск чтения ключа macOS не заменяет разрешение на передачу. Не ослабляй ACL хранилища ради удобной проверки.

## Проверка результата на Mac

Повтори `df -k "$HOME"` и показатель контейнера. Запиши время обоих снимков, число выбранных/сохранённых/пропущенных файлов и exit-коды. После очистки кэша проверь штатное открытие приложения; после переноса — хэши, целостность и пользовательский сценарий. Если ещё ничего не удалялось, напиши «удалений не было»; увеличение free от параллельной сессии не приписывай себе.
