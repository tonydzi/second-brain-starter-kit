# Windows: размер, восстановление, чистка

## Замер без изменений

Определи версию Windows/PowerShell, пользователя, корни из конфигурации и нужные тома. Не переноси Mac-пути на Windows и не угадывай, что данные находятся на C:.

```powershell
Get-Volume | Where-Object { $_.Size -gt 0 } |
    Select-Object DriveLetter, FileSystemType, Size, SizeRemaining
Get-ChildItem -LiteralPath $env:USERPROFILE -Force -ErrorAction Stop |
    Select-Object Name, Attributes, Length
```

Второй пример показывает первый уровень и логические размеры файлов; это не замер папок целиком. Для рекурсивного инвентаря обходи уровни явно, сначала проверяя Attributes. Не заходи в junction/symlink/reparse point и другой том. Ошибки доступа — пропуски, не нули. `$?` фиксируй сразу для cmdlet; `$LASTEXITCODE` относится к внешнему процессу. Используй `-ErrorAction Stop` и обработку исключения для проверяемого cmdlet.

`Length` не равен занятому месту у compressed/sparse-файлов и облачных заглушек. Есть проверенный инструмент allocated size — укажи его и версию; иначе сообщай логическую оценку отдельно от `SizeRemaining`. NTFS hard links не должны многократно увеличивать сумму. Не выдавай виртуальную ёмкость VHD за занятое место на хосте.

OneDrive Files On-Demand может показывать полный размер локальной заглушки. Открытие, хэширование или копирование может скачать файл. Сначала проверь атрибуты и статус синхронизации. «Free up space» убирает локальную загрузку, сохраняя облачный файл; обычное Delete может удалить его в облаке и на других устройствах. Это отдельное согласованное действие. [Microsoft: Files On-Demand](https://support.microsoft.com/en-us/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows).

## Важные кандидаты

| Объект | Что проверить до действия |
|---|---|
| `%TEMP%`, AppData, пакетные кэши | Владелец и содержимое. AppData содержит базы, профили и секреты. Не чистить рекурсивно всё дерево. |
| Windows Update/component store | Штатные Cleanup recommendations/Disk Cleanup для выбранных категорий. Не удалять вручную WinSxS или Windows Installer. |
| Windows.old | Возможность отката и пользовательские остатки. Отдельное решение после проверки; это не обычный кэш. |
| Recycle Bin/Downloads | Не очищать целиком, не включать автоматическую очистку. Проверить защищённые и единственные файлы. |
| WSL/Hyper-V/Docker `.vhdx` | Владелец, volumes/distro и данные внутри. Не удалять, не выполнять unregister или prune-volumes ради места. |
| Restore points/shadow copies | Функция восстановления. Не удалять и не менять лимит по ходу обычной чистки. |
| Модели/сборки/репозитории | Точная доступная версия, уникальное состояние и стоимость пересоздания; общие критерии SKILL.md. |

Штатный интерфейс: Settings → System → Storage → Cleanup recommendations; для старой системы — Disk Cleanup. Просмотри выбранные категории до подтверждения: Downloads, корзина и предыдущая Windows не получают разрешение автоматически. Не включай Storage Sense и не меняй расписание по запросу разовой чистки. [Microsoft: освобождение места](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows).

## Виртуальные диски и выборочный перенос

После удаления внутри WSL/VM занятое место внутри и размер `.vhdx` на хосте могут меняться по-разному. Сначала инвентарь и восстановление; compact/resize — поддерживаемым методом для установленной версии, после остановки владельца и отдельного согласования. Максимальная ёмкость WSL-диска не означает столько же занятого на Windows. [Microsoft: WSL disk space](https://learn.microsoft.com/en-us/windows/wsl/disk-space).

Пути передавай как literal path, без масок. Проверь все компоненты корней на reparse point и границы томов: junction может увести обход за выбранную папку. [Microsoft: reparse points](https://learn.microsoft.com/en-us/windows/win32/fileio/reparse-points).

Не используй `robocopy /MIR` или `/PURGE`. `Copy-Item` не гарантирует отказ при существующем назначении: применяй создание с CreateNew или проверенный механизм без перезаписи. Dry-run показывает выбранные пути, но не доказывает восстановимость. SHA-256 сравнивай для обычных полностью локальных файлов; reparse/облачные/секретные исключи. Между ОС проверь коллизии регистра, запрещённые символы и длинные пути.

Для SQLite/браузеров действуют общие правила SKILL.md. Профиль, зашифрованный DPAPI другой учётной записи/машины, не станет рабочим от копирования файла. Не переносить всё защищённое хранилище и не расшифровывать секреты в отчёт; используй поддерживаемый перенос и явное разрешение владельца.

## Проверка результата на Windows

Повтори `Get-Volume` того же тома. Отдельно запиши изменение `SizeRemaining` и удалённый объём; освобождение внутри VM не выдавай за освобождение хостового диска. Проверь восстановление/приложение и ошибки команд. До прогона на настоящем Windows этот документ имеет статус «процедура описана», а не «проверено на Windows».
