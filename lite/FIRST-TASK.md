# Первая полезная задача

Выберите одну настоящую задачу владельца. Уберите из входа пароли, банковские
данные, частную переписку третьих лиц и то, что не хотите отдавать выбранному приложению.
Помощник не ищет новые источники вне выбранной папки без просьбы.

Простой пример для первого запуска: **список дел превратить в список покупок**.
Владелец сам даёт свой список; помощник группирует его и сохраняет результат.
Проверка: каждый исходный пункт есть, ничего лишнего не добавлено, количество не выдумано.

Если настоящая задача пока не выбрана, используйте пробный вход:

```text
Для ужина нужны рис, морковь и лук. Для завтрака — овсянка и яблоки.
Лук уже есть дома. Разбей список покупок на ужин и завтрак. Количество не знаю.
```

Ожидаемое содержимое: ужин — рис и морковь, завтрак — овсянка и яблоки. Лук отдельно
отмечен как имеющийся дома. Нет цен, количества, магазина или новых продуктов,
придуманных помощником. Названия обеих групп уже есть во входе.
Эта проба проверяет механику; полезность для владельца доказывает его настоящая задача.

Затем сделайте короткую записку: какую задачу решали, где результат, что проверили,
что продолжать. Откройте новый чат в той же библиотеке и передайте эту записку.
Проверка продолжения: помощник правильно называет результат и следующий шаг.

Статус первого запуска: «проверен на задаче владельца» только после проверки
владельцем. До этого: «проба выполнена» или «ожидает первой задачи».
